# Glossary

Terms the method uses, in plain words. Where Harry has a stance, it's included.

| Term | Japanese | What it means | Don't mix it up with |
|---|---|---|---|
| acquisition |  | Picking language up naturally from understood input, as opposed to memorising it. |  |
| active immersion |  | Sitting down fully locked in on native content, trying to understand it (the one-video grind replays lines on purpose; enjoyable active watching just keeps going). |  |
| active vocabulary |  | Words so familiar they just come out when you speak. |  |
| advanced |  | You understand nearly everything; the work is fine-tuning speaking and understanding complex topics. |  |
| Anki |  | A phone/PC flashcard app whose algorithm tells you when to review each card. |  |
| Anki add-on |  | An optional plug-in that adds a feature to Anki, such as the JIL pitch accent display. |  |
| Anki Browser |  | Anki's search window where you find, select, edit, move or suspend cards. |  |
| Anki deck settings |  | Per-deck Anki options such as new cards per day, learning steps and review limits. |  |
| Anki stint |  | A short burst of new Anki cards on one topic's words before you immerse in that topic (a new niche, a field for work). Harry still does them. |  |
| AnkiWeb |  | Anki's sync service: puts all your cards on the web so you can use the phone app or another computer. |  |
| API key |  | A private code that lets one program (e.g. Claude Code) use another service's account, such as ElevenLabs. |  |
| apkg |  | Anki's deck file format; opening the file imports the deck. |  |
| aspiration |  | Puffing air on consonants like t (a tissue in front of your mouth moves). |  |
| base |  | Your words, grammar and kanji: the knowledge you study first so you can understand input. |  |
| boke and tsukkomi | ボケ / ツッコミ | Comedy roles: the boke says something deliberately stupid so the other can make fun of it; the tsukkomi is the retort. |  |
| bottleneck |  | Whatever is limiting your progress right now (e.g. vocab, ears or grammar); spot it and fix exactly that. |  |
| brute force |  | Grinding a card with two or three unknown words until it sticks. Fine for the odd early card; normally each card has one new word. |  |
| card audio |  | A sound clip of the word or sentence attached to an Anki card, often AI-generated. |  |
| causative | 使役 | Verb forms for 'let me do it', 'he made me', 'I was allowed to'. |  |
| chunk |  | A small piece of Japanese halfway between a phrase and a piece of grammar (どっちかというと, というわけで, みたいな感じで). You build sentences out of chunks plus words; as important as grammar. |  |
| Claude |  | Anthropic's AI assistant; Harry's recommended AI for word lists, sentence cards and grammar explanations. | Claude (chat) is not Claude Code (runs on your computer and does jobs for you). |
| Claude Code |  | An AI that lives inside your computer and can run commands, so it does jobs for you, not just answers. |  |
| Claude skill |  | Where you save a repeatable process or reference (e.g. your known-word list, someone's voice) for Claude to reuse. |  |
| comprehensible input |  | Language you can mostly understand, so it teaches you; the idea behind immersion learning. |  |
| connectors |  | Linking words and phrases between sentences that make speech flow and sound native. |  |
| critical mass |  | The point past which your progress starts snowballing very quickly. |  |
| desu/masu (polite form) | です・ます | The standard polite sentence and verb endings; the safe default with people you've just met. |  |
| dialect | 方言 | A regional way of speaking (hougen); in Okinawa and Amami it is practically a separate language. |  |
| dictionary form |  | A verb's standard base form; all its conjugated forms count toward it. |  |
| dictionary-definition words |  | Words used a lot inside dictionary definitions but hardly anywhere else. |  |
| Duolingo |  | A gamified app built on short daily lessons and streaks. Not part of Harry's method. |  |
| ElevenLabs |  | An AI voice service that generates spoken audio and can train custom voices. |  |
| English keyword |  | A single English word attached to each kanji so you learn to recognise and tell kanji apart. |  |
| feedback loop |  | Something that confirms you're right, e.g. using a phrase with a native and watching the reaction, or finding a real native example. |  |
| filler words | えっとね / あの | Ums, ahs and in-between words (e.g. etto ne, ano) that connect thoughts in real speech and don't count as vocab. |  |
| first principles |  | Breaking the huge thing that is Japanese down to its smallest parts and attacking those first before expanding. |  |
| first-person pronouns | 俺 / 僕 / 私 / うち | The different words people use to call themselves 'I' (ore, boku, watashi, uchi), each giving a different image. |  |
| fluency |  | Saying what you want to anyone, young or old, posh or poor, on any topic without major restrictions. |  |
| frequency list |  | Every word used in a source (e.g. one channel), ranked from most common to least common. |  |
| front-loading vocab |  | Learning about 4,000-5,000 words in the first three to six months, then maximising listening. |  |
| furigana | 振り仮名 | Small kana printed above kanji to show how they are read. |  |
| gaijin | 外人 | Foreigner; the gaijin bubble is foreigners grouping together. |  |
| Genki |  | A popular beginner textbook series. Not part of Harry's method: Tae Kim read once, then immersion. |  |
| Good / Again buttons |  | Anki's answer buttons: Again if you forgot, Good if you remembered; how strictly you press them is your grading. |  |
| grammar drills |  | Exercises like turning a verb into its negative or past-tense form. |  |
| gyaru | ギャル | A flashy, outgoing young women's fashion subculture. |  |
| hard subtitles |  | Subtitles on the video that you cannot turn off. | Opposite of soft subtitles. |
| HelloTalk |  | Free app matching Japanese learners with Japanese people learning English; Twitter-like posts plus messaging and calls. |  |
| Hikaru | ヒカル | Japanese YouTuber (UFO catchers, gacha, challenges, with his manager 店長) with natural, fairly fast speech that mixes standard Japanese and Kansai-ben, and thousands of videos. The default first creator to build your niche on. | The Hikaru 500 (the deck) or the JIL Tracker (the logging site). |
| Hikaru 500 |  | The JIL starter deck: the 500 most common words in Hikaru's videos as sentence cards, one new word per card, with standard pitch and audio. | Hikaru himself (the YouTuber) or the JIL Tracker. |
| hiragana | ひらがな | The basic rounded phonetic script, used for grammar endings and native words. |  |
| i+1 |  | Content just above your level: a sentence where you know everything except one word. |  |
| i-adjective | い形容詞 | Adjectives ending in -i that conjugate themselves, e.g. takai. |  |
| immersion |  | Contact with Japanese the way a native gets it, e.g. Japanese YouTube, rather than textbooks or study. |  |
| inner voice |  | How you pronounce words in your head, which you then reproduce when you speak. |  |
| input |  | Reading and listening, which build your mental model. |  |
| Instagram Reels |  | Instagram's short-video feed; its algorithm can be trained to show you Japanese content. |  |
| intermediate |  | In this course: everything after the base. Once you've done the Hikaru 500, read Tae Kim once and done the kanji deck if you needed it, you're intermediate. It's about the base being done, not a JLPT level. |  |
| JIL Tracker |  | Harry's website for logging your immersion (active or passive), setting goals and seeing your stats. Access comes with your membership. | The Hikaru 500 (the deck) or Hikaru himself. |
| JLPT | 日本語能力試験 | Japan's official proficiency exam (N5 easiest to N1 hardest); it has no speaking or writing section, so vocabulary is the real barrier. |  |
| JLPT deck |  | The JIL deck of 7,160 JLPT words, built for passing the test. Only for people sitting the JLPT. |  |
| JLPT levels (N5-N1) | N1 | The five JLPT grades, from N5 (beginner) to N1 (near-native reading and listening). |  |
| kana | 仮名 | The two Japanese phonetic scripts, hiragana and katakana; each symbol is one sound. |  |
| kanji | 漢字 | Chinese-origin characters that carry meaning; most Japanese words are written with them. |  |
| kanji deck |  | The optional 300-kanji deck: kanji on the front, English on the back, just to get used to recognising kanji. For true beginners without a Chinese-language background. |  |
| kanji writing deck |  | A deck with a word's hiragana on the front; you write its kanji from memory. |  |
| Kansai-ben | 関西弁 | The Kansai (Osaka, Kyoto) dialect: different pitch accent, faster speech that joins words, drops particles and condenses grammar. |  |
| katakana | カタカナ | The angular phonetic script, mostly used for foreign loanwords and emphasis. |  |
| keigo | 敬語 | Honorific speech: polite, respectful and humble forms used with seniors, strangers and at work. |  |
| known-word list |  | A list of every word you already know (built from your deck), fed to the deck builder so it skips them; grows as you learn. | Not the word list you make new cards from. |
| L/H notation |  | Marking each part of a word L for low or H for high pitch. |  |
| language exchange |  | Swapping practice with a native speaker who is learning your language, usually through an app like HelloTalk. |  |
| language parent |  | One native speaker whose way of talking you like and deliberately copy, since people sound like whoever they hear most. |  |
| learner content |  | Japanese content made for learners rather than for Japanese people. | Opposite of native content. |
| mass listening |  | Listening to very large amounts of native Japanese over a long time. |  |
| master deck |  | The one Anki deck your own cards go into (from the deck-maker or the Claude chat), not split by video or topic. The Hikaru 500 stays its own deck. |  |
| measuring stick |  | Native Japanese you constantly compare your own speech against. |  |
| mental model |  | Your sense of how Japanese should sound (pronunciation, rhythm, timing, word choice), built from lots of understood listening; you copy it to speak. |  |
| micro-dosing |  | Fitting immersion into short blocks (15-30 minutes) spread through the day. |  |
| minimal pairs |  | Two words that differ in only one sound or pitch, used to test whether you can hear the difference. |  |
| mining |  | Collecting the words you don't know (from your video or ones that pop out) to turn into sentence cards with Claude. | Also used loosely for collecting any unknown words into cards, not only i+1 sentences. |
| mnemonic |  | A memory trick, such as a little story, used to remember something like a kanji. |  |
| monolingual |  | Using Japanese-only (J-J) definitions instead of English; the monolingual transition is switching your cards and dictionaries over to them. |  |
| na-adjective | な形容詞 | Adjectives that take na before a noun, e.g. shizuka na. |  |
| native content |  | Content made by Japanese people for Japanese people, not simplified for learners. | Opposite of learner content. |
| near-synonym |  | Words very similar in meaning that all translate to the same English word. |  |
| new cards |  | Cards you see for the first time each day, as opposed to reviews. |  |
| niche |  | One small area of Japanese, e.g. one YouTuber or one topic, that you focus immersion and words on before the whole language. |  |
| niche deck |  | Your own deck made with Claude from the content you watch. |  |
| noun-modifying clause |  | Japanese puts the whole description before the noun, e.g. 'the garden-picked vegetables'. |  |
| one-for-one equivalent |  | A direct English equivalent you could learn instantly, as most nouns have. |  |
| output |  | Speaking or writing, done by copying and replicating your mental model. |  |
| parsing |  | Your brain taking in audio, picking out the sounds, and turning them into words and then meaning. |  |
| particle | 助詞 | Small words after a word that mark its role in the sentence, like は, が, を, に. |  |
| passive immersion |  | Japanese playing in the background while you commute, walk or do chores, tuning in and out. Put your current one-video-method video on repeat here. | Active immersion (sit-down, full attention). |
| passive vocabulary |  | Words you understand when reading or listening but can't bring out when speaking or writing. |  |
| pitch accent | アクセント (高低アクセント) | The high-low pitch pattern built into each word's pronunciation, like stress in English words. | Not the same as 'accent' (overall native-sounding pronunciation). |
| premade deck |  | A deck made by someone else from a general word list, who chose the words, sentences and definitions for you. Not used in the method: you make your own cards from what you watch. The JIL starter decks are the exception: the Hikaru 500 (the most common words, which don't change from person to person) and the JLPT deck (built only for passing the test). |  |
| progressive overload |  | Get used to remembering, keep pushing, and do a little more each day. |  |
| prompt |  | The written instructions you give an AI. |  |
| pronunciation |  | How you physically make and string together the sounds: accent, intonation and rhythm. |  |
| radical |  | A building-block part of a kanji, often hinting at its meaning. |  |
| raw content |  | Content without subtitles. |  |
| read the air | 空気を読む | Sensing the mood and what people mean without it being said, and keeping things subtle. |  |
| reading (kanji) | 読み | How a kanji is pronounced; each kanji can have many readings. | Means pronunciation, not the skill of reading text. |
| Remembering the Kanji |  | A kanji method that links each kanji to an English keyword and has you write it from memory. Harry did it and gave it up; he advises against it. |  |
| retention |  | Getting a word to stick in Anki, as distinct from hearing it in immersion; also shown as the % of reviews you pass. |  |
| reviews |  | Cards Anki shows you again because they are due; they pile up if you skip days. |  |
| romaji |  | Japanese written in the Latin alphabet. |  |
| sentence breakdown |  | The explanation on the back of a card of what each word and grammar point in the sentence means. |  |
| sentence card |  | Anki card with a sentence (ideally one unknown word) on the front; its meaning and full breakdown on the back. |  |
| set phrase |  | A full fixed phrase learned as a block, often not one-for-one in English, and rarely heard in the exact form you learned. |  |
| shadowing | シャドーイング | Repeating audio aloud just behind the speaker, trying to match them exactly. Harry's view: a waste of time; record yourself and compare instead. |  |
| Skool |  | The online community platform that hosts Harry's Japanese Immersion Lab: course, Q&A posts, calls and deck prompts. |  |
| slang |  | Informal everyday words and sayings, including internet slang, that textbooks leave out. |  |
| soft subtitles |  | Subtitles you can switch on or off and download as a file, so the words can be pulled out. | Opposite of hard subtitles, which are burned into the video. |
| sound system |  | How the language sounds: its tonality and the little pauses Japanese people use. |  |
| spaced repetition |  | Cards you get right come back at growing intervals (next day, 3 days, 7 days), so reviews are spaced out. |  |
| speed-run method |  | Anki shortcut: show the answer straight away, read the breakdown, picture the word, press Good. |  |
| standard Japanese | 標準語 | The standard (Tokyo) form of Japanese, whose pitch accent everyone knows; hyoujungo. |  |
| subtitles |  | On-screen text of what is said; auto-generated ones are made by the platform's speech recognition. |  |
| suspend |  | Freezes cards completely so they don't appear until you unsuspend them. |  |
| Tae Kim |  | A free grammar website (not an app) that walks through all Japanese grammar, each point described with example sentences. |  |
| tameguchi | タメ口 | Casual speech, as used with friends and equals. |  |
| target word |  | The one unknown word a sentence card is built to teach. |  |
| te-form | て形 | The verb form ending in -te/-de, used to link actions and build many grammar patterns. |  |
| thinking in Japanese |  | Talking to yourself in Japanese in your head all day (narrating what you do or think) to practise and iron things out. |  |
| three stages (base, mental model, output) |  | His three-part method: base (words, grammar, kanji), then mental model (listening and parsing), then output (speaking). |  |
| tolerating ambiguity |  | Getting used to not fully understanding words, grammar and sentences, and letting immersion fill the gaps. |  |
| training ground / fight night |  | Your head is the training ground where you practise speaking; talking to real people is fight night. |  |
| transcript |  | The full text of everything said in a video or audio, downloaded or generated. |  |
| two sides of speaking (ease and accuracy) |  | Speaking has two parts: ease (how easily the words come out, built by practice) and accuracy (how close you are to how natives speak, set by your mental model). Ease is capped by accuracy. | 'Ease' here is about speaking, not Anki's ease factor. |
| volume problem |  | You know about 90% of the words when reading but catch about 10% by ear, because your brain hasn't adjusted to the speed. | Opposite diagnosis to the word problem: here the words are known, the ears are the gap. |
| word card |  | Anki card with just the word on the front and its definition on the back. |  |
| word list |  | A list of words you take and make your own cards from. | Not the known-word list (words you already know, fed to the deck builder). |
| word problem |  | Even reading the subtitles you don't know most of the words, so you have to build vocabulary first. | Opposite diagnosis to the volume problem: here the words are the gap, not the ears. |
| X (Twitter) |  | Social network for short posts, heavily used in Japan; good for reading real native phrasing. |  |
